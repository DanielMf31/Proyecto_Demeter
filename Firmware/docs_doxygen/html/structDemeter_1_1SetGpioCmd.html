Detailed Description

Configuración digital (ON/OFF) a aplicar sobre una salida de GPIO.

Representación lógica interna (aislada del CBOR) que el orquestador usará para demandar un cambio al Controlador Físico de Pines.

Ejemplo de uso:
SetGpioCmd cmd = {4, true, 0}; // Encender Pin 4
gpioCtrl.handleCommand(cmd);
