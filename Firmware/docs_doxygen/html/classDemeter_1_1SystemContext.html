Detailed Description

Contexto Centralizado del Sistema Demeter.

Responsable de gestionar la identidad (Id, Rol), el estado actual de la conexión y la configuración de energía profunda (Deep Sleep) para el Nodo local.

Ejemplo de uso:
SystemContext ctx;
ctx.setIdentity(2, NodeRole::SENSOR, 1);
ctx.setState(SystemState::RUNNING);
if (ctx.getState() == SystemState::RUNNING) {
// Execute tasks
}
