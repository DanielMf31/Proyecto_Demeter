Detailed Description

Agrupa y orquesta una colección heterogénea de sensores de Hardware.

Permite que nodos complejos tengan N sensores independientes. Centraliza el proceso de muestreo devolviendo un vector curado de lecturas exitosas.

Ejemplo de uso:
SensorManager sm;
sm.addSensor(new DhtSensor(22));
sm.begin(); // Inicializa buses (I2C, OneWire)
auto readings = sm.readAll();
for(auto& r : readings) {
print(r.temperature);
}
