Detailed Description

Capa de Abstracción de Hardware (HAL) para Control GPIO.

Gestiona los pines físicos del microcontrolador (ESP32). Desacopla la lógica de negocio de la API de Arduino (digitalWrite, pinMode).

Ejemplo de uso:
GpioController gpio;
gpio.setPins({4, 5});
gpio.init();
Demeter::SetGpioCmd cmd = {4, true, 0};
gpio.execute(cmd); // Pin 4 se pone a HIGH

◆ execute()

void GpioController::execute ( const Demeter::SetGpioCmd &  cmd)

Ejecuta una orden de Cómputo Digital sobre el Hardware.

Recibe un objeto comando estructurado y lo inyecta al hardware.

Internamente invoca digitalWrite de la API de Arduino. Sólo actúa sobre el pin si se encuentra dentro de _managedPins o si la orden tiene flags de "force".

Parameters
cmdEstructura Demeter::SetGpioCmd con el target PIN y su nivel logico.

¿Por qué el argumento es Demeter::SetGpioCmd y no (uint8_t pin, bool val)? Facilita extender el protocolo. Si mañana el comando añade parámetros como duration o fade_speed (para PWM), la firma de esta función no se rompe, solo se extrae el nuevo campo del Struct.
