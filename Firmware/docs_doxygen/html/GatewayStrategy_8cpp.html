Detailed Description

Implementación del enrutador híbrido (Multiplexor).

DECISIONES DE ARQUITECTURA Y DISEÑO

  1. Patrón Decorador / Proxy: Al sistema central no le importa que el Gateway tenga dos tarjetas de red (Puerto Serie y Antena WiFi). El GatewayStrategy implementa IComms (es una estrategia), pero recibe dos IComms en su constructor. Básicamente intercepta los .send() y decide a quién "sub-enrutarlo".
  2. Enrutamiento por ID (ID 0): En Demeter, el ID 0 está reservado para el "Servidor Host" (backend en Raspberry Pi). Si el frame detecta Destino=0, sale por el cable USB/UART. Cualquier otro ID viaja por WiFi P2P (ESP-NOW) hacia los nodos de la finca.
