Detailed Description

Interfaz Abstracta para la Capa de Comunicaciones Físicas.

Implementa el Patrón Estrategia (Strategy Pattern) aislando el formato de los paquetes lógicos del medio físico subyacente. Implementaciones concretas: UartStrategy, EspNowStrategy.

Ejemplo de uso polimórfico:
IComms* comms = new EspNowStrategy();
comms->begin();
std::vector<uint8_t> payload = {0x01, 0xFF, 0x00};
comms->send(payload.data(), payload.size());
EspNowStrategy
Implementación de IComms especializada en el stack ESP-NOW de Espressif.
