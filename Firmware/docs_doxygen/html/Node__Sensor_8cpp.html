Detailed Description

Firmware lógico para el Nodo Extremo de tipo Sensor.

DECISIONES DE ARQUITECTURA Y DISEÑO

  1. Por qué aislar la lógica Sensórica en una clase concreta (Herencia de INode)? Porque un Nodo Sensor tiene un ciclo de vida fundamentalmente diferente a un Actuador o Gateway. Este nodo debe dormir profusamente (Deep Sleep) para ahorrar batería (es de borde lejano).
  2. Desacoplamiento del Hardware Específico: Observa que no instanciamos un sensor DHT o I2C directamente aquí. Este nodo tiene un objeto genérico SensorManager. Al componerlo de este gestor abstracto, esta clase sirve para cualquier combinación de sensores atmosféricos que hagamos.
