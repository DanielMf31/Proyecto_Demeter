Detailed Description

Estructura Genérica para Lecturas de Sensores.

Soporta nativamente hasta dos magnitudes de punto flotante. En Demeter V2, se utiliza predominantemente para Temp/Hum.

Ejemplo de uso:
Demeter::SensorReading read = { 25.4f, 60.1f, true };
if (read.isValid) { sendTx(read); }
