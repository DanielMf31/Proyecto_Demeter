◆ CommandType

enum class Demeter::CommandType : uint8_t
strong

Command IDs for the Demeter Protocol V2.

Note
Must match the Python definition in schemas_protocol.py.
Enumerator
PING 

Keep-alive check. Expects ACK.

ACK 

Acknowledge successful command receipt.

NACK 

Negative Acknowledge (Error).

SYN 

Synchronize (Handshake 1/3).

SYN_ACK 

Synchronize-Acknowledge (Handshake 2/3).

ROUTE_ADD 

Register a new route in the routing table.

TEMP_HUM_REPORT 

Report Sensor Data (Temp/Hum). Replaces DATA_REPORT.

PIN_REPORT 

Report GPIO Pin State change.

SYSTEM_REPORT 

Report System State (Mode, Battery).

SET_GPIO 

Set Digital Output state.

SET_PWM 

Set PWM Duty Cycle.

EXEC_SEQUENCE 

Execute a complex sequence of actions.

GET_SENSORS 

Request Sensor Data.

UNKNOWN 

Fallback for invalid commands.

◆ NodeRole

enum class Demeter::NodeRole
strong

Rol de Despliegue Lógico. Define qué conjunto de características lógicas se orquestarán.

Enumerator
SENSOR 

Solo recolecta y envía reportes. Típicamente a batería.

ACTUATOR 

Responde a comandos (Relé/PWM) y devuelve confirmaciones.

GATEWAY 

Actúa como sumidero (Sink) de mensajes y conversor a WiFi/Backend.

HYBRID 

Mixto actuador y sensor, típicamente enchufado a corriente.
