Detailed Description

Implementación Concreta de Comunicación Serie (UART).

Puentea la interfaz IComms a la clase nativa HardwareSerial del framework Arduino. Soporta Mocking si se des-comenta el macro NATIVE_ENV para tests en Linux.

Ejemplo de uso:
// Instanciar sobre UART2 en ESP32
UartStrategy uart2(&Serial2, 115200, 16, 17);
uart2.begin();
if (uart2.available()) {
auto frame = uart2.read();
}
