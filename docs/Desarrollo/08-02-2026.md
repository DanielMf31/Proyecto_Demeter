## 🛠️ Decisiones Técnicas
*   **MVP vs Arquitectura Completa:** Se decidió "hardcodear" la GUI de Python y desacoplar componentes para priorizar una prueba end-to-end rápida en lugar de integrar todo el sistema de Agentes/Configuración complejo de primeras.
*   **Tkinter:** Se eligió por ser estándar en Python, aunque requiere instalación de sistema (`python3-tk`) en Linux.

## 🚧 Bloqueos y Soluciones
*   **Error:** `ModuleNotFoundError: No module named 'tkinter'` en Linux.
    *   **Causa:** Tkinter no viene en el Python mínimo de Linux.
    *   **Solución:** `sudo apt-get install python3-tk`.
*   **Entorno Pi:** Necesidad de un entorno virtual limpio.
    *   **Solución:** Creación de `requirements_mvp.txt` y guía paso a paso.
