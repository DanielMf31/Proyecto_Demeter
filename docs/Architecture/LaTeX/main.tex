\chapter{Arquitectura del Servicio Raspberry Pi}
\label{anx:raspberry}

Este anexo detalla la arquitectura del servicio Python ejecutado en la Raspberry Pi,
que actúa como pasarela de borde (\textit{edge gateway}) entre la red de nodos ESP32
y el servidor central. El servicio se ejecuta en un contenedor Docker con acceso
directo al puerto serie GPIO (\texttt{/dev/serial0}) y gestiona cuatro tareas
AsyncIO concurrentes: transporte UART, cliente WebSocket, servidor HTTP local
(FastAPI en el puerto 8001) y el despachador de comandos.
Los diagramas de este anexo cubren la arquitectura de componentes, los flujos
de telemetría y comandos, el despliegue Docker y las tareas asíncronas.

\chapter{Arquitectura del Backend}
\label{anx:backend}

Este anexo presenta los diagramas de la arquitectura del servidor central desplegado
en Google Cloud Platform. El backend se compone de seis contenedores Docker
(API FastAPI, frontend Nginx, PostgreSQL, Redis, math-worker RQ y secuenciador)
interconectados a través de la red privada \texttt{demeter-net}.
La comunicación con la Raspberry Pi se realiza mediante WebSocket y el despacho
de comandos utiliza el patrón Redis Pub/Sub descrito en el Capítulo~\ref{sec:backend}.
